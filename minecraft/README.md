# 我的世界 · 网页版（Minecraft Web）

高还原度《我的世界》网页版小游戏。自研体素引擎 + Three.js，纯前端实现，无需构建。

## 运行方式

直接双击 `index.html` 用浏览器打开即可（需联网加载 Three.js CDN）。

也可以使用本地服务器：

```bash
# Python
python -m http.server 8000 --directory minecraft

# Node
npx serve minecraft
```

然后访问 `http://localhost:8000`。

| 按键 | 功能 |

| `H` | 显示/隐藏帮助 |

## 还原的 MC 特性

- **无限程序化地形**：值噪声 + 分形叠加生成大陆、丘陵、海洋、沙滩，区块边长 16 与 MC 一致
- **17 种方块**：草方块、泥土、石头、沙子、橡木原木、树叶、基岩、水、煤矿石、铁矿石、圆石、木板、玻璃、罂粟、蒲公英、草
- **程序化 16×16 像素纹理**：草皮下垂、原木年轮、树叶透明镂空、矿石斑点，全部由 Canvas 生成
- **MC 原版物理**：重力 32 m/s²、跳跃高度 1.25 格、行走 4.3 m/s、眼高 1.62、触及距离 5 格
- **创造模式交互**：左键即挖、右键放置、准星高亮线框、不可在玩家身体内放置
- **氛围**：10 分钟日夜循环、方块云、视距雾、半透明水面
- **其他**：9 格物品栏、第一人称手持方块（行走摆动）、F3 调试屏、localStorage 自动存档

## 技术要点

- **体素渲染**：每区块合并为单个 Mesh，只生成暴露面（面剔除），纹理图集 + UV 映射
- **面明暗着色**：顶点色模拟 MC 环境光（顶面 1.0 / 侧面 0.8、0.6 / 底面 0.5）
- **地形纯函数化**：任意坐标方块可独立计算，树木按 5×5 网格确定性分布，跨区块结果一致
- **碰撞检测**：AABB 逐轴解算，支持跳跃、游泳、飞行
- **射线检测**：DDA 体素遍历算法
- **存档**：仅持久化玩家修改的方块差量 + 位置 + 种子，localStorage 存储

## 文件结构

```
minecraft/

├── game.js      # 游戏引擎（地形生成/渲染/物理/交互/存档）

```

## 已知限制

- 渲染距离默认 4 区块（可在 `game.js` 中调整 `RENDER_DIST`）
- 无生物、无音效、无合成系统（纯建造玩法）
- Three.js 从 CDN 加载，离线无法运行
