# 热血篮球 FC（Nekketsu Street Basket 复刻）

用 HTML5 Canvas + 原生 JavaScript 高度还原 FC 经典《热血！街头篮球》（熱血！すとりーとバスケット がんばれ Dunk ヒーローズ）。零依赖、零素材，全部像素图形与音效由代码生成。

## 运行方式

- 直接双击 `index.html` 即可游玩（无需构建、无需联网）；
- 或启动本地服务：`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 操作说明

| 功能 | 1P | 2P | 触屏 |
|------|----|----|------|
| 移动 | A / D | ← / → | 左侧虚拟摇杆 |
| 跳跃 | K | . | 「跳」按钮 |
| 投篮 / 攻击（无球）/ 扔道具 | J | , | 「投」按钮 |
| 传球 | L | / | 「传」按钮 |
| 开始 / 确认 | Enter | Enter | START / 「投」 |

- 持球跳起后靠近篮筐按「投篮」→ **扣篮**（必中，撞飞防守者）；
- 跳到对手头上可**踩人弹起**（二段跳，对手受伤）；
- 无球时走过道具自动捡起，按「投篮」扔出。

### 移动端支持

- 触摸设备自动显示**虚拟摇杆**（左下）与**虚拟按钮**（右下：投/跳/传，顶部 START），支持多指同按（摇杆移动 + 按钮同时触发）；
- 摇杆带死区与方向沿触发，菜单界面同样可用（摇杆选择 + 「投」确认）；
- 竖屏时显示「请横屏游玩」提示；触屏模式下 1P 由摇杆操作（2P 仍需键盘）；
- PC 上可用 `index.html?touch=1` 强制开启触屏控件预览布局。

## 高度还原要素明细（对照 FC 原版）

### 1. 比赛规则
- 2 vs 2 街头篮球，无犯规、自由攻击；
- 常规时间 3 分钟，平分进入 30 秒**加时金球制**（先得分者胜）；
- 标志性**三层篮架**：下筐 2 分 / 中筐 3 分 / 上筐 4 分，筐越高越难扣（跳跃属性决定可达高度，助跑跳 +8% 高度）；
- 中圈跳球开场、得分后失分队底线发球（90 帧保护时间）。

### 2. 操作与动作（还原 FC 手感）
- 地面：跑 / 跳 / 原地投篮（14 帧出手动作）/ 出拳 / 传球；
- 空中：跳投 / 扣篮（吸附篮筐动画 + 挂筐）/ 飞踢；
- 投篮命中率模型：`0.30 + 投篮属性×0.09 - 距离衰减 + 跳投加成 - 防守干扰`，结果分空心入网 / 打铁弹出 / 三不沾；
- 扣篮必中并震屏，路径上撞开防守球员。

### 3. 暴力系统
- 拳击（力量属性决定伤害）、飞踢、踩头；
- 体力槽（头顶显示，缓慢回复），打空体力强制**倒地 85 帧** + 起身**眩晕**（头顶星星）；
- 持球者被打会**掉球**（fumble），形成抢断。

### 4. 道具系统（随机刷新，最多同时 2 个）
| 道具 | 效果 |
|------|------|
| 石头 | 砸中 24 伤害并强制倒地 |
| 轮胎 | 砸中 12 伤害，落地后持续滚动撞人 |
| 垃圾桶 | 套头 5 秒：移动减半且无法投篮 |
| 香蕉皮 | 落地成陷阱，踩到滑倒 |

### 5. 场地与机关（5 个）
| 场地 | 机关 |
|------|------|
| 屋顶 ROOFTOP | 标准场地 |
| 体育馆 GYMNASIUM | 标准场地（观众席动画） |
| 冰场 ICE RINK | 超低摩擦，滑行 |
| 沙滩 BEACH | 高摩擦 + 跳跃力 -8% |
| 工地 FACTORY | 两段双向**传送带** |

### 6. 队伍与球员（6 队 × 2 人）
热血 / 花园 / 冷峰 / 太阳 / 美国 / 俄罗斯，每名球员有 **速度 / 跳跃 / 力量 / 投篮** 四维属性（1~5）与独立配色，选人界面可视化属性条。

### 7. 画面表现
- 256×240 FC 逻辑分辨率，3 倍整数缩放 + `image-rendering: pixelated`；
- 二头身 Q 版角色，18 组动作帧全部由代码逐像素生成（调色板换色实现队伍/球员差异）；
- 横向卷轴摄像机（场地宽 480 ≈ 两屏）+ 多层视差背景；
- 5×7 自制像素字体 HUD、扣篮震屏、粒子特效（火焰 / 星星 / 尘土）；
- 游戏内文字全英文像素字，还原 FC 无中文字库的质感。

### 8. 音效
Web Audio 实时合成 8-bit 音效 16 种：跳跃 / 投篮 / 传球 / 运球落地 / 打铁 / 进球 / 扣篮 / 拳击 / 倒地 / 哨声 / 终场蜂鸣 / 菜单音等，无任何音频文件。

### 9. AI
状态机决策（每 5 帧一次）：持球进攻（按跳跃力选筐扣篮 / 空位投篮 / 被包夹分球）、无球跑位、盯人防守 + 出拳抢断 + 起跳盖帽尝试、协防篮下、抢地板球、捡道具砸人。

### 10. 游戏模式
- 1P VS CPU（队友 AI 辅助）
- 2P VS CPU（双人合作）
- 1P VS 2P（双人对战，各带一名 AI 队友）

## 技术架构

```
fc-basketball/
├── index.html        入口，按依赖顺序加载 js/
├── style.css         像素化渲染、居中布局
└── js/
    ├── constants.js  常量、篮架几何、6 支队伍数据
    ├── utils.js      数学/碰撞工具
    ├── audio.js      Web Audio 音效合成器
    ├── input.js      键盘 → 虚拟 FC 手柄（按住/按下沿双状态），合并触屏输入
    ├── touch.js      移动端虚拟摇杆 + 按钮（写入 Touch* 虚拟键码，与键盘同构）
    ├── sprites.js    5x7 像素字体 + 角色帧/球/道具的程序化像素画
    ├── entities.js   Player（13 态状态机）/ Ball（抛物线+筐沿碰撞）/ Item / Particle
    ├── ai.js         CPU 决策状态机
    ├── stages.js     5 个场地定义（摩擦/跳跃修正/传送带/视差背景绘制）
    ├── match.js      比赛流程：跳球→进行→得分→发球→加时金球→终场，HUD/卷轴/震屏
    ├── menu.js       标题→模式→选人→选场地→结算
    └── main.js       固定步长（60Hz）主循环与场景切换
```

### 关键实现
- **投篮物理**：给定出手点、目标筐心与飞行时间，反解抛物线初速度 `vx=dx/T, vy=(dy-½gT²)/T`；命中判定为球心自上而下穿越筐口水平线，未命中时与两个筐沿做圆形碰撞反弹（打铁）；
- **固定步长循环**：`requestAnimationFrame` 累加器 + 60Hz 逻辑步进，保证不同刷新率下手感一致；
- **渲染**：逻辑层全部在世界坐标绘制，摄像机通过单次 `translate(-cam)` 实现卷轴，远景层用 `cam×视差系数` 补偿；
- **零素材**：角色帧在初始化时由像素函数绘制到 offscreen canvas 缓存，换色即换队。
